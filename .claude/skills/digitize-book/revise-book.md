# 改订：原书错误（A）与旧用词（B）

数字版是**改订版**：内容仍以原书为准，但订正明显错误、把旧用词换成现代说法。所有改动都要可追溯。

## 第一步：找候选（只读）

按章分组并行派 agent 扫源码，**只出候选清单，不改任何文件**。每路写一份报告到 scratchpad，并在回复里给精简表。

- **A 类（原书错误）**：例题、习题、答案的算术和单位换算，用 python 验算；前后矛盾；答案与题设不符；引用错误；错别字。
- **B 类（旧用词）**：术语、单位、人名译名、旧化学名、过时数据；每条给"现代说法"和出现频次（`Grep` 统计）。
- 把握度分高/中/低，A 类附验算依据，不要凑数。

## A 类：原书错误

1. 先按 [verify-scans.md](verify-scans.md) 对扫描：**是录入错误就直接订正**。
2. 确是原书错误：按把握度分
   - 高把握（有验算、答案可互证）→ 向负责人汇报后改；
   - 中低把握（近似误差如 51° vs 53.1°、史实年份、表述不严）→ 照录，只登记在 REVISIONS 第五节。
3. 题目与答案矛盾时的处理原则（项目负责人已定）：**以题目为准修改答案**；只有答案整齐而题设数字磨损时才改题设。
4. 改源码时在改处加注释 `/* 原书作 xxx（扫描确印） */`（行内用块注释；`//` 注释后同一行不能再跟 `]`）。
5. 登记 REVISIONS：已改的进第三节（页码｜位置｜原书｜数字版｜状态），照录的进第五节。

## B 类：旧用词

先在 `common/TERMINOLOGY.md` 登记，再改。**处理方式有三种**（项目负责人已定的判断标准）：

| 处理 | 适用 | 例 |
|---|---|---|
| 替换 | 纯用字、译名、名称，改了不影响数字和定义 | 弹簧秤→弹簧测力计，tg→tan，象→像，伽俐略→伽利略 |
| 加注 | 牵涉定义、单位换算或成体系的用语；正文照原书，首次出现处加一条数字版注 | 重量（即重力）、公斤（力）、压强单位、马力、离心力 |
| 照录 | 仍通用或属时代用语 | 水银、参照物 |

已定的取舍（沿用，不要重新讨论）：

- 比重 ≠ 密度：书里比重＝重量/体积（现代“重度”），第 7 章专门区分两者。不整体替换；第 2 章定义处加注；**习题、例题题干和解答里重述的已知数据"比重为 x 克/厘米³"改称"密度"**；"求……的比重"的问句、公式 γ、表 2·1 保留。
- 公里→千米整体替换（只换名称，"小时"不动）。公斤（力）、重量不替换，合并进第 2 章一条数字版注。
- 标题里的旧词与正文一并替换（目录会同步）。

### 批量替换

```powershell
# terms.tsv：每行"旧词<TAB>新词"，re: 开头为正则
python scripts/replace-terms.py --book physics-1 --map terms.tsv          # 先试运行看计数
python scripts/replace-terms.py --book physics-1 --map terms.tsv --apply  # 再写入
just check
```

- 脚本跳过 `//` 和 `/* */` 注释（保留 `原书作 xxx`），跳过标题行并报告出来。
- **有歧义的词必须用正则限定**：`象`（排除现象、对象、象限）、`二个`（排除"第二个"）、`粘`（只改粘滞、粘性，保留粘合、粘贴）。先试运行，对 `re:` 规则逐条看上下文。
- 整词替换不逐处加 `// 原书作` 注释，以 TERMINOLOGY.md + REVISIONS 第二节的一行为准。

### 加数字版注

- 用 `#dnote[现代说法……]`，加在**首次出现处**的句末标点之后；不要加在边注（`#sidenote`）里，不要插在词组中间。
- 用"锚点字符串 → 锚点+注文"的脚本批量插入，**每个锚点必须只出现一次**（`assert count == 1`），页码从源码页标记取，顺手生成 REVISIONS 的行。
- 注文只说事实：现代说法、换算（如 1 公斤力≈9.8 牛顿）、两种用法的区别；不评价原书。
- 希腊字母脚注统一"英文名＋英式音标"（如 gamma /ˈɡæmə/）。

## 收尾

- `just check` → 更新 `TERMINOLOGY.md` 状态（建议→已定）→ REVISIONS 加行 → 提交。
- REVISIONS 第五节只留"原书如此、照录"的项，已改的要移走，避免新旧矛盾。
