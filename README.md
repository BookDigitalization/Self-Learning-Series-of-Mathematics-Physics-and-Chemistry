# 数理化自学丛书 · 数字化重排

把上海科学技术出版社出版的《数理化自学丛书》（1960–70 年代版）扫描版 PDF，用 [Typst](https://typst.app) 重新排版成清晰、可检索、可复制的数字版 PDF，供普及教育使用。

> 本项目仅供学习研究，**请勿用于商业目的**。项目源码以 [CC BY-NC-SA 4.0](LICENSE) 授权，详见文末[版权说明](#版权说明)。

**本项目重现的是内容，不是版面。** 文字、公式、数据、编号、章节结构忠实于原书；字号、页面、配色、分页等版式交给统一的现代图书模板。

> **关于准确性**：本项目的录入、对照扫描核对、改订和版面通读，都是由 AI 完成的，人工只做了抽查和关键决定。尽管每册都经过独立的二次核对，仍可能有录入错误（文字、公式、数字、图中标注）、误改或遗漏。如果你发现任何问题，欢迎到本仓库[提交 Issue](../../issues)，请写明分册、原书页码和正确内容，我们会对照扫描核实后修正。

## 进度

各册按“录入 → 逐章对照扫描核对 → 改订（订正原书错误、旧词现代化）→ 整书版面通读 → 发版”五个阶段推进（做法见 `.claude/skills/digitize-book/`）。**已有 10 册发布于 [Release v0.0.2](../../releases/tag/v0.0.2)（含成书 PDF 与各册改订记录）。** 各册改动见该册 `REVISIONS.md`，存疑处见 `CHECKLIST.md`。
